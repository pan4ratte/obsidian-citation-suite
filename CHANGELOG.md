# Changelog

## 1.0.0

### New features

* **Citing through Zotero's own window.** A hotkey or a command opens the same citation window Zotero's word-processor plugins use — with the page, the prefix, the suffix and the "suppress author" switch. The pick is inserted into the note the moment that window closes.
* **Citations in pandoc syntax.** A pick becomes `[@doe2020, p. 33]`, and several sources become one group separated by `;`. A locator holding a comma is written in braces instead, so pandoc does not cut the citation short at it.
* **Inserting what is selected in Zotero.** Another command takes the items selected in Zotero's window and cites them without opening the citation window at all.
* **Citations shown in a Zotero style.** The note still holds the pandoc citation; reading view and live preview draw it as the chosen Zotero style writes it, page, prefix, suffix and suppressed author included. Sources are taken from My Library and from group libraries alike; when the same key is in several, the item in My Library is used. Hovering over a citation shows the bibliography entry of every source it cites. The style is chosen in the settings from a list of every style, just like the one in Zotero's "Document preferences" window, and a sample citation in the chosen style is shown under the list — in live preview, which is the default, in reading view or in source mode, switched with the buttons beside the sample's title. Source mode no longer draws citations in their style: it shows the note exactly as it is written. A bar of buttons above the sample sets the look of citations: the color of the citation and its underline (the accent by default, body text or a custom one), the underline (dotted, solid, squiggly or none), bold and italic; putting the cursor inside a citation shows it as written.
* **Citations in footnotes.** With the setting on, a footnote anchor is placed at the cursor and the citation becomes the footnote's text — after the current paragraph, at the end of the current section or at the end of the note. Footnote numbers are written in arabic or roman numerals, and text of your own can be added before and after the number. The sample citation in the settings shows it in a footnote too, with the anchor a note's first footnote would get.
* **The note's bibliography.** A tab in the right sidebar lists every source the note cites, written in the chosen style, with its sorting, numbering and indentation. The tab opens the first time the plugin runs, and the "Show bibliography" command brings it back once closed. Above the list are the number of entries, a search of the list and a button that copies it the way Zotero's "Copy Bibliography" does: formatted for a word processor, and as plain text. The search keeps only the entries holding every word typed — by author, title, year or citation key. Right-clicking an entry opens a menu: reveal the source in Zotero, copy just that entry, or find it in the note — a bar then appears under the entry that steps from one mention of the source to the next. The entries themselves are what Zotero writes: items are taken in the form Zotero hands them to citeproc, and the engine is set up the same way. The list follows the open note and updates as you type, and the keys Zotero has no item for are listed under it.
* **Settings.** The brackets can be turned off, the port of Zotero's local server can be changed (24119 for the beta), and Zotero's window can be minimized as soon as the pick is done.
